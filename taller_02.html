Python + API SAP2000

Automatiza la modelación, el análisis y la extracción de resultados en SAP2000 mediante Python.

Acerca del taller

Este taller presenta una introducción práctica al uso de Python y la API de SAP2000 para automatizar tareas habituales de modelación y análisis estructural. A partir de un ejemplo guiado, aprenderás a conectar ambos programas, generar un modelo estructural, ejecutar el análisis y recuperar resultados mediante código.

El taller incluye un código base comentado que podrás adaptar y ampliar para desarrollar tus propias herramientas de automatización.

¿Qué aprenderás?

  • Conectar Python con SAP2000 mediante su API.
  • Crear elementos y definir la geometría de un modelo estructural.
  • Ejecutar un análisis modal espectral de manera automatizada.
  • Consultar y organizar resultados directamente desde Python.
  • Exportar información para su revisión y procesamiento posterior.

¿A quién está dirigido?

Dirigido a estudiantes, ingenieros y profesionales del área estructural que utilizan SAP2000 y desean incorporar Python a su flujo de trabajo. No se requiere experiencia previa trabajando con la API, aunque se recomienda manejar conceptos básicos de análisis estructural y tener conocimientos introductorios de Python.
